# 导航与布局 v2（人体工学版）

> lead 产出 · 2026-11-18 · 分支 feature/apifox-ui-parity
> 背景：v1 把 12 条路由平铺在左树 + 又平铺一遍在水平页签条（重复导航），且右侧栏实际可用宽约 500px，
> 240px 左树 + 主区 + 240px 右栏三段式在窄容器里必然拥挤；doc/test/schema/env/mock/debug 页内又各自带左树，
> 形成「树里套树」。v2 改为 **图标轨 + 浮层二级菜单**，把导航收进 48px，主区拿回全部宽度。

## 1. 结构（三级菜单，全部不撑开主区）

```
┌─────────────────────────────────────────────────────────┐
│ 顶栏 44px  当前页 · 面包屑 · 搜索 · 动作（图标按钮）      │
├────┬────────────────────────────────────────────────────┤
│ 轨 │ 主区（1fr，宽度最大化）                            │
│ 48 │  ┌ 页头（标题 + 描述 + 页面级动作）               │
│ px │  ├ 内容                                           │
│    │  └                                                │
│ ①  │                                                    │
│ ②  │        ← 二级浮层菜单（打开时覆盖在主区上，       │
│ ③  │          不挤压主区宽度；Esc / 点外部关闭）        │
│ ④  │                                                    │
│ ⑤  │                                                    │
└────┴────────────────────────────────────────────────────┘
```

- **一级：图标轨 48px**（`.pp-rail`）——5 个分组图标，永远可见，只占 48px。
- **二级：浮层菜单 200px**（`.pp-flyout`）——点分组图标后从轨右侧浮出，绝对定位覆盖主区，
  **不改变主区宽度**；再点同图标或按 Esc / 点浮层外关闭。
- **三级：分组内的路由条目**（`.pp-flyout-item`）——点即跳转，跳转后浮层自动关闭。

## 2. 五个分组（12 条路由的归类）

| 分组 | 图标语义 | 路由 |
|---|---|---|
| 项目 | 网格 | 总览 `overview` |
| 接口 | 文档页 | 文档 `doc`、调试 `debug`、Mock `mock` |
| 数据 | 数据库 | 数据模型 `schema`、环境 `env` |
| 质量 | 勾选 | 测试 `test`、历史 `history`、流程图 `flow` |
| 工具 | 齿轮 | 导入导出 `import`、搜索 `search`、设置 `settings` |

## 3. 顶栏（44px，密度更高）

- 左：当前页标题（`.pp-crumb`）+ 分组名面包屑（灰色，`/` 分隔）。
- 中：搜索框（`.pp-topbar-search`，宽度自适应，最大 320px）。
- 右：动作组——新建接口（主按钮）、环境下拉、主题（图标）、设置（图标）。**全部图标化或紧凑**，
  不留长文案按钮，避免窄栏挤压换行。

## 4. 页头（每个页面统一，主区内）

`.pp-page-head`：标题 `.pp-page-title` + 一行描述 `.pp-page-desc` + 右侧动作区 `.pp-page-actions`。
页头与内容间距 `--sp-4`，页头下不再画分割线（靠留白分组，减少线条噪音）。

## 5. 页面内实体树改为「面板」

页面内原有的左树（doc 的目录/接口、env 的环境、schema 的模型、test 的用例、mock/debug 的接口列表）
统一改成 `.pp-panel`：白底、1px 边框、8px 圆角、内部 padding 8px，宽 200px（`--panel-w`），
与主内容用 `gap: var(--sp-4)` 分开。**不再用 `.pp-col-left` 边框通栏**，避免与工作台边框重复。

## 6. 人体工学要点（硬约束）

1. 主区在任何路由下都不被导航挤压：浮层菜单用 `position: absolute`，**不得**用 grid 列。
2. 单页纵向滚动只发生在主区（`.pp-main { overflow: auto }`），轨与顶栏固定。
3. 所有可点目标最小 28×28（`--hit: 28px`），轨图标 20px。
4. 焦点可见：`:focus-visible` 必须有 2px 外环（`--accent-tint`）。
5. 浮层动画 120ms 淡入 + 4px 位移，`prefers-reduced-motion` 时关闭。
6. 窄容器（< 420px）时浮层宽度降到 176px（`--flyout-w-sm`），顶栏搜索收起为图标。

## 7. 新增 token

| token | 值 | 用途 |
|---|---|---|
| `--rail-w` | 48px | 图标轨宽 |
| `--flyout-w` | 200px | 二级浮层宽 |
| `--flyout-w-sm` | 176px | 窄容器浮层宽 |
| `--panel-w` | 200px | 页面内实体树面板宽 |
| `--hit` | 28px | 最小可点尺寸 |
| `--topbar-h` | 44px | 顶栏（原 48 改 44） |
| `--rail-icon` | 20px | 轨图标尺寸 |
| `--z-flyout` | 30 | 浮层层级 |
| `--motion-fast` | 120ms | 浮层动画时长 |

## 8. 移除项（v1 遗留，必须删）

- 水平全局页签条（`.pp-tabs` 在 Body.js 的那一条）——与轨重复，且吃掉 40px 纵向。
  页面内部的 `.pp-tabs`（Params/Headers/Body/Auth 等）保留。
- `.pp-body-3col` / `.pp-col-left` / `.pp-col-right` 作为工作台骨架的用法（页面内也不再使用）。
- 右上下文栏（`.pp-col-right` 的页面说明 + 快捷入口）——信息价值低但占 240px。
  改为顶栏右侧一个「?」图标按钮，点开浮层显示当前页说明与快捷入口。

## 9. 验收

1. `node build.mjs` 通过，产物含 `--rail-w`。
2. `node tests/run.js` 全绿（shell-frame 断言改为 rail/flyout 结构）。
3. `heights.test.js` PASS（新 token 纳入检查）。
4. `ui-audit.test.js` 软清单 0 问题。
5. 真机截图：主区宽度 ≥ 容器宽 - 48px；浮层打开时主区宽度不变。
